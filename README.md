# Lambda House Homebrew tap

```sh
brew install --cask lambda-house/tap/mdviewer
```

[MDViewer](https://github.com/lambda-house/mdviewer-mj) is a Markdown viewer with Mermaid diagrams, syntax highlighting and an agent workspace. `Casks/mdviewer.rb` is updated by the MDViewer release workflow; don't edit it by hand.
